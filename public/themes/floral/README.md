# Aset PNG Tema "Floral Blossom"

Letakkan file aset PNG/WEBP berlisensi komersial di folder ini. Setelah lengkap,
aktifkan dengan mengubah `FLORAL_USE_PNG = true` di
`src/features/theme/floral-assets.js`.

Selama `FLORAL_USE_PNG = false` (default) atau file belum ada, sampul tetap
memakai ornamen SVG bawaan (tidak ada yang rusak).

## Slot file yang dibutuhkan (nama HARUS persis)

| Nama file | Wajib? | Isi | Rekomendasi |
|---|---|---|---|
| `flower-1.png` | ✅ | Bunga tunggal (mis. dahlia pink) — latar transparan | ~800–1200px, PNG transparan |
| `flower-2.png` | ✅ | Bunga tunggal (mis. mawar) | sama |
| `flower-3.png` | ✅ | Bunga tunggal (mis. lili putih) | sama |
| `flower-4.png` | ✅ | Bunga/kuncup kecil | sama |
| `flower-5.png` | ✅ | Bunga besar (mis. peony/dahlia peach) | sama |
| `leaf.png` | ✅ | Rumpun dedaunan hijau (dipakai berulang di atas) | ~600–1000px, transparan |
| `cover-bg.webp` | ⬜ opsional | Latar taman dreamy (pink/lavender) | 1080×1920 (potret HP) |
| `photo-frame.png` | ⬜ opsional | Bingkai foto floral, lubang tengah transparan | rasio ~3:4 |
| `petal.png` | ⬜ opsional | Satu kelopak kecil (untuk hujan kelopak) | ~100–200px, transparan |

> Tip: cukup **5 bunga + 1 daun** untuk hasil yang sudah mirip mengundanganda
> (mereka pun me-reuse 5 gambar bunga + 1 daun, diputar/dicerminkan).

## Di mana cari aset (berlisensi komersial)

Cari kata kunci (PNG **transparan**, **isolated/cut-out**):
- "watercolor flower png transparent", "floral clipart png isolated"
- "watercolor bouquet png", "eucalyptus greenery png transparent"
- "pink dahlia png", "white lily png transparent", "blush rose png"

Sumber (pilih yang izin **commercial use**):
- **Freepik** — banyak gratis (sering butuh atribusi) & Premium (tanpa atribusi).
- **Vecteezy**, **rawpixel** — banyak watercolor floral PNG.
- **Envato Elements**, **Creative Market** — langganan, lisensi komersial luas.

## ATURAN LISENSI (penting)
- Pastikan lisensi mengizinkan **penggunaan komersial** (ini produk SaaS).
- **JANGAN** memakai gambar milik mengundanganda (CDN `media.mengundanganda.com`)
  — itu pelanggaran hak cipta.
- Simpan bukti/lisensi setiap aset.
- Idealnya pilih yang **tanpa wajib atribusi**; jika wajib, taruh kredit di
  halaman kredit/footer.
